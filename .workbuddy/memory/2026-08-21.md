## 本地预览终于跑通（Ruby/Jekyll on Windows，本机无可用 MSYS2 devkit）
- 环境：RubyInstaller 3.3.6-1 装在 C:/Ruby33，但 DevKit 的 MinGW64 gcc **没装**（msys64 只有 make，pacman/keyring 在该沙箱里损坏：pacman-key --init 在陈旧锁文件上死循环，SigLevel=Never 也不生效）。
- 死路：github-pages 元 gem 锁死旧 nokogiri/racc/http_parser.rb/json，Ruby 3.3 UCRT 下这些 gem 无预编译二进制、必现场编译 → 失败。预编译路线也走不通（jekyll 3.9 经 em-websocket 硬依赖 http_parser.rb 0.8.1，本机无 ucrt 预编译）。
- 终解：**下载独立 MinGW-w64 UCRT 工具链**（winlibs posix-seh gcc-16.2.0）到 C:/mingw64/mingw64/bin；配合本地 `Gemfile.local`（plain `jekyll 3.9.0` + 所需插件，去掉 github-pages）。
- 关键坑：RubyInstaller 生成的 gem Makefile 用 MSYS2 风格路径 `/C/Ruby33/...`，而 winlibs gcc 只认 `C:/...`，导致 ruby.h 找不到。用环境变量兜底解决：
  `C_INCLUDE_PATH="C:/Ruby33/include/ruby-3.3.0;C:/Ruby33/include/ruby-3.3.0/x64-mingw-ucrt"`、`CPLUS_INCLUDE_PATH` 同、`LIBRARY_PATH="C:/Ruby33/lib"`。
- Gemfile.local 还显式补了 github-pages 原本顺带提供、但 jekyll 3.9 gemspec 没声明/已移出 stdlib 的依赖：`tzinfo`+`tzinfo-data`（Windows 时区）、`kramdown-parser-gfm`（GFM 输入）、`webrick`（Ruby3 serve 用）。并移除 `_config.yml` 里 `jekyll-gist`（→faraday→json 编译失败，且内容没用到 gist）。
- 启动：`./serve_local.sh`（已建，封装上述 PATH/环境变量 + `BUNDLE_GEMFILE=Gemfile.local bundle exec jekyll serve --host 127.0.0.1 --port 4000 --livereload`）。服务已在 http://127.0.0.1:4000 验证返回 200、用户内容改动均生效。
- 注：`Gemfile`（github-pages）保持原样不动，部署不受影响；Gemfile.local 仅供本机预览。
- 待清：`preview/` 废弃文件（P0）；两篇共同作者论文缺封面图。

## 项目/实习卡片右侧空白 → :has() 修复
- 用户截图指出"项目经历" / "实习经历" 卡片右侧 40% 空白，bullet 内容挤在左 60%。
- 根因：AcadHomepage 基类 `.paper-box { display:flex; flex-wrap:wrap }`，配套规则 `.paper-box-text { order:2; max-width:60%; padding-left:2em }` 假设有图（image 在 40%、text 在 60%）。当 box 里只有 text（如项目卡片）没图时，text 仍被 60%/2em 限制。
- 修复：`_sass/_job-profile.scss` 加 `:not(:has(.paper-box-image)) .paper-box-text { max-width:100%; padding-left:0 }`。有图的卡片（如出版物）保持 60% 不变。
- `:has()` 兼容性：Chrome 105+ / Safari 15.4+ / Firefox 121+，足够现代。

## 侧栏姓名分两行（用户两次截图反馈，最终解决）
- 截图 1/2：`李晨涛 Chentao` + `LI` 折成三段。
- 第一次改：`<span>` + CSS `display:block` + `white-space:nowrap`。
- 服务端 HTML/CSS 都正确，但截图仍显示旧样式 → **浏览器 CSS 缓存**（jekyll LiveReload 不一定能绕过）。
- 第二次改：把 `<span>` 换成 `<div>`，**让块级成为标签默认行为**，不再依赖 CSS；CSS 只管字体/颜色。HTML 验证两个 `<div>` 已渲染。
- 用户第三次截图（17:40）：显示 `李晨涛` / `Chentao LI` 两行布局，**问题解决**。
- 经验：当 jekyll livereload 改动 CSS 后用户仍看不到效果，怀疑浏览器缓存时，**改 HTML 标签语义**比改 CSS 更可靠——浏览器对 HTML 缓存策略通常更松、且区块渲染不依赖单条 CSS 规则。
